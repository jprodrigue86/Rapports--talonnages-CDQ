# V21.37 — Balance Quvre 4 et copies locales

Version 2026.09.15.1530-v21.37. Apps Script : déploiement 272, même URL et mêmes permissions.

Balance Intermédiaire propose Balance Quvre 4 avec le PDF final sur quatre appuis. Le maître demeure dans le dossier système; chaque rapport est une copie.

Le modèle est préparé automatiquement après une connexion autorisée. Il reste dans IndexedDB sur cet appareil. Le module public ne contient aucun PDF ni données client. Le bouton Modèles hors ligne permet de télécharger le maître et de créer des copies locales, y compris après un redémarrage sans réseau. Le déverrouillage au redémarrage utilise la biométrie déjà inscrite sur cet appareil.

Pour préparer une destination, ouvrir le dossier client puis Balance Intermédiaire avec Internet. Les copies locales sont synchronisées une fois CDQ reconnecté et déverrouillé. Une opération rejouée utilise le même identifiant et ne crée pas de doublon. Le serveur vérifie de nouveau les droits et l’appartenance du dossier. Si le modèle a été remplacé entre-temps, la copie locale est conservée et un message invite à la récupérer.

Le téléchargement d’un PDF rempli reste le comportement du lecteur ouvert depuis ce panneau. Le PDF rempli téléchargé doit être rapporté dans CDQ selon le flux existant.

Validation : PDF binaire identique; destination locale; doublon réseau; numérotation; droits; révision du maître; 11 tests de biométrie et 9 tests de connexion existants.
