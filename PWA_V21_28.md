# V21.28 — Accès stable du créateur

Build coordonné : `2026.09.15.2030-v21.28`.

Le compte créateur est maintenant reconnu côté serveur et n'utilise plus de code d'activation. Une session créateur déjà reconnue n'est plus effacée à l'ouverture d'une nouvelle version. Le panneau d'administration affiche « Créateur » et bloque la génération d'une clé pour ce compte.

Le jeton d'appareil est aussi conservé dans l'origine stable de la PWA. Le sélecteur Google le récupère avant sa première vérification d'accès et le remet à jour après une autorisation réussie. Cette persistance évite qu'un changement d'origine temporaire du cadre Google transforme une mise à jour en nouvel appareil.

Les techniciens conservent le parcours prévu : code d'activation lors du premier enregistrement de l'appareil, puis biométrie ou NIP aux ouvertures suivantes.

Validation automatisée : 9 tests créateur, 23 tests de régression, 9 tests du sélecteur, 18 tests photos et modèle, 23 tests documents, 8 tests d'ouverture, 11 tests PWA et 11 tests biométriques.

Les fichiers privés `Code.gs` et `Selector.html` ne sont pas publiés dans ce dépôt.
