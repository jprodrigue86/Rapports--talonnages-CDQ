CDQ Apps Script Manager — Android

Version V8 — validation Android/PWA

1) Ouvrir dans Google Chrome :
   https://jprodrigue86.github.io/Rapports--talonnages-CDQ/apps-script-manager/

2) Chrome > menu ⋮ > Installer l’application.

3) Première utilisation Google :
   - Le Client OAuth doit autoriser l’origine JavaScript https://jprodrigue86.github.io
   - API Google Apps Script activée
   - API Google Drive activée

4) Utilisation :
   - Se connecter à Google
   - Choisir le projet Apps Script
   - Lire le projet
   - Modifier un fichier OU coller un Package CDQ
   - Vérifier
   - ÉCRIRE DANS APPS SCRIPT
   - Optionnel : créer une version / déployer

Format Package CDQ :
=== FILE: Code.gs ===
...code...
