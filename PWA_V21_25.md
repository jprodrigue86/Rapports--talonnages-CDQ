# Photos et modèle PDF V21.25

Le bouton de copie ouvrait sa confirmation, mais sa fonction de destination était dans le CSS et ses appels visaient des fonctions privées d'un autre script. Le sélecteur compagnon corrige ces portées, affiche les erreurs et copie le PDF maître dans le dossier client ouvert, sur téléphone comme sur ordinateur.

Les nouvelles photos sont rangées dans `_CDQ_SYSTEME / nom du client / AAAA-MM-JJ`. La date et le décalage horaire sont capturés avant compression et conservés en attente hors ligne. Le serveur résout le client depuis la cible réelle et réutilise les dossiers par identité client. Les anciennes pièces jointes restent consultables. Les envois sont conservés avant l'appel réseau, dédupliqués et repris après déverrouillage; une synchronisation conserve aussi les nouvelles photos ajoutées pendant son exécution.

Le maître PDF est remplacé par la dernière version avec navigation et zoom sans marges. Ses octets et champs interactifs sont conservés. Une nouvelle préparation **Hors ligne ON** charge ce modèle sur le téléphone; une copie locale de l'ancien maître n'est plus utilisée par cette version. Un téléchargement interrompu par un changement du maître est refusé.

Cette publication coordonne le numéro de version PWA, le cache de démarrage et les compagnons privés Apps Script. Le protocole biométrique V21.24 reste identique.

Validation : 60 scénarios locaux distincts, dont 18 ciblant les photos et la copie, les 42 précédents incluant 10 tests généraux PWA. Le test de cache utilise désormais le nom de cache déclaré par le service worker. Le PDF installé dans Drive a la même empreinte SHA-256 que le fichier source validé. Les tests simulés ne remplacent pas une prise photo ou une empreinte sur le téléphone réel.
