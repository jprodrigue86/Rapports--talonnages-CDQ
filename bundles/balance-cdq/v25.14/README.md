# Balance CDQ V25.14 — jeux d’icônes personnels

Dans **Réglages → Thème → Jeu d’icônes**, choisir les icônes actuelles ou l’un des quatre jeux de l’image fournie : **4 Minimaliste**, **5 Dark Pro**, **6 Metal Music**, **7 3D isométrique**. Le choix remplace les six icônes de navigation du bas et conserve leurs actions et leurs dimensions.

- Compatible avec les packages **V25.12 et V25.13**. Intègre les dimensions compactes et le retour par glissement de V25.13.
- Installation par **CDQ Script Manager V40**, puis **ÉCRIRE + DÉPLOYER**. Aucun changement d’APK requis.
- Choix local distinct pour chaque compte CDQ; synchronisation via la session CDQ authentifiée, avec reprise après une interruption réseau. Les autres préférences restent inchangées.
- L’image de référence fournie est embarquée sans modification. Les cadrages CSS affichent les icônes sans leurs légendes d’origine. Les icônes restent disponibles hors ligne.
- Le bouton Dossier conserve son icône fonctionnelle lorsqu’il passe à une autre action, par exemple Dupliquer.

Validation : tests des comptes séparés, réponses de synchronisation tardives, sauvegarde différée, retour aux icônes actuelles, curseur de taille et affichage Chromium à 320, 384 et 412 px. Application du package vérifiée sur les sources privées reconstituées, qui ne sont pas publiées. La confirmation sur le téléphone réel reste à faire.

Les captures de test ne sont pas téléversées dans GitHub Actions, afin de limiter le stockage temporaire.
