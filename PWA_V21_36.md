# V21.36 — Choix du modèle de balance intermédiaire

Le bouton Balance intermédiaire propose trois PDF : Balance de plancher,
Balance de cuve 4 points et Balance de cuve 3 points.

Le modèle choisi est copié dans le dossier client ouvert. Les noms existants
sont conservés et les nouvelles copies sont numérotées. Chaque modèle possède
son propre cache hors ligne; la file de synchronisation conserve le choix.

Les sources métier et les PDF restent privés. Ce dépôt ne contient que la
mise à jour du numéro de version et du lien de lancement de la PWA.
Le lecteur PDF V21.33 est conservé.

Validation : 11 scénarios d’intégration des modèles et 11 contrôles PWA réussis.
