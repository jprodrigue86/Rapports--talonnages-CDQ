Installer Balance CDQ

Installez d’abord l’application. Ouvrez ensuite l’icône Étalonnages pour vous connecter.

Ouvrir ce lien dans le navigateur

Le navigateur intégré d’une messagerie peut empêcher l’installation. Ouvrez cette page dans Chrome sur Android, ou dans Safari sur iPhone.

Cette page ne lance pas la connexion Google. Le navigateur demandera votre confirmation pour installer l’application.

Ouvrez maintenant l’icône CDQ

L’installation peut prendre quelques secondes. Revenez à l’écran d’accueil ou à la liste des applications, puis ouvrez Étalonnages.

Installation sur Android

  1. Ouvrez cette page dans Chrome, pas dans la fenêtre de Messenger ou de Facebook. Vous pouvez copier le lien ci-dessous et le coller dans Chrome.
  2. Dans Chrome, touchez ⋮ → Installer et créer un raccourci → Installer. Selon la version : Ajouter à l’écran d’accueil → Installer.
  3. Confirmez, puis ouvrez l’icône Étalonnages depuis votre écran d’accueil ou la liste des applications.
  1. Ouvrez cette page dans Safari.
  2. Touchez Partager → Sur l’écran d’accueil. Activez Ouvrir comme app web si cette option est proposée, puis touchez Ajouter.
  3. Revenez à l’écran d’accueil et ouvrez l’icône Étalonnages.
  1. Ouvrez cette page dans Chrome ou Edge.
  2. Utilisez l’icône d’installation dans la barre d’adresse ou la commande d’installation d’application dans le menu du navigateur.
  3. Confirmez l’installation de Rapports D’étalonnages.

Si l’installation n’est pas proposée, vérifiez d’abord si l’icône Étalonnages existe déjà. L’absence de bouton ne prouve pas que l’application est absente.

Un seul lien à transmettre

L’application est déjà installée ?

Ouvrez directement son icône sur votre téléphone. Ne désinstallez rien et ne videz pas les données : des rapports peuvent être enregistrés sur l’appareil.

Accéder à CDQ dans ce navigateur

Ce lien ouvre le site. Il ne garantit pas le basculement vers l’application déjà installée.

Installation et activation sont deux étapes différentes. Cette page ne demande aucune clé, aucun NIP et aucune autorisation d’accès aux rapports.

Après installation, le parcours de connexion prévu est : compte Google → clé d’activation à usage unique → NIP à quatre chiffres → biométrie facultative.
